# Screenshots Directory

This directory contains approved screenshots of the HEC Pharm platform.

## Files

- `landing-page.png` - Homepage hero section
- `3d-globe.gif` - Animated demonstration of the interactive globe
- `molecular-viewer.png` - 3D molecular visualization interface
- `dashboard.png` - Analytics dashboard overview
- `mobile-responsive.png` - Mobile device view

## Guidelines

- All screenshots must be approved before public display
- No sensitive data should be visible
- Use placeholder/demo data only
- Maintain consistent dimensions (1920x1080 for desktop, 375x812 for mobile)

## Creating Screenshots

1. Use demo/staging environment only
2. Clear all personal/sensitive data
3. Use high-quality capture tools
4. Optimize file sizes (use PNG for static, GIF for animations)
